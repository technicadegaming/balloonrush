# Three-Button Service Controls

Physical cabinet buttons:

| Physical control | Attract | Gameplay | Operator browse | Operator edit |
|---|---|---|---|---|
| LEFT | service-code input | move left | previous item | decrease value |
| POP / UP | start game | pop balloon | activate/select | confirm value |
| RIGHT | service-code input | move right | next item | increase value |

## Hidden service entry

From Attract Mode, enter within six seconds:

`LEFT LEFT RIGHT RIGHT LEFT RIGHT LEFT RIGHT RIGHT LEFT RIGHT LEFT`

This opens Operator Menu without a keyboard or dedicated operator button.

## Operator workflow

Browse with LEFT/RIGHT. The selected control has a cyan focus outline.

For a button or toggle, press POP to activate it.

For a value field:
1. press POP to edit (focus becomes gold),
2. press LEFT/RIGHT to change it,
3. press POP to confirm,
4. browse to SAVE SETTINGS and press POP when finished.

The diagnostics overlay is handled the same way. While it is open, only diagnostics buttons participate in navigation.
